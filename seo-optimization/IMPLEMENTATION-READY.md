## 📞 SUPPORT & QUESTIONS

### Si .htaccess ne fonctionne pas:
1. Vérifier permissions: 644
2. Vérifier AllowOverride = All
3. Vérifier mod_rewrite activé
4. Restaurer backup `.htaccess-old`

### Si SQL error:
1. Vérifier noms colonnes (adapter si nécessaire)
2. Backup d'abord!
3. Exécuter sur copie DB ou staging
4. Tester SELECT avant UPDATE

### Si site plante:
1. Restaurer `.htaccess-backup`
2. Supprimer fichiers problématiques
3. Restaurer DB si nécessaire
4. Vérifier logs serveur
